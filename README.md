# Qlib RAG System
This repository contains the complete Python implementation for our RAG system. We used fixed random seeds to ensure reproducibility.

Here are the setup instructions:
1. Install Ollama and pull the Llama 3.2 model: 'ollama run llama3.2'
2. Install dependencies: 'pip install -r requirements.txt'
3. The dataset crawler is built into the Python script so it will construct the dataset locally.

To execute, simply run the following command:
'python rag_pipeline.py'
